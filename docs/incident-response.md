# Incident response

1. Acknowledge and assign; preserve evidence references and timestamps.
2. Validate scope and corroborate signals. Do not state that a breach is confirmed prematurely.
3. Request payload-bound approval for containment; use the least disruptive action.
4. Eradicate and recover under change control; monitor recurrence.
5. Notify legal/privacy stakeholders using jurisdictional playbooks.
6. Complete lessons learned, evidence retention, and control updates.
