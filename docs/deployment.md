# Deployment

Use managed PostgreSQL/Redis in private subnets, a public WAF/CDN, private security ingress, workload identity, KMS-backed secret manager, and a service mesh enforcing mTLS. Run scanners on tainted isolated nodes with no cloud metadata route, read-only filesystems, dropped capabilities, egress allowlists, CPU/memory/time quotas, and ephemeral volumes. Sign images with keyless provenance, admit verified signatures, generate SBOMs, and forward audit/telemetry to a separate SIEM account. Encrypt backups and conduct quarterly restore and regional recovery exercises.
